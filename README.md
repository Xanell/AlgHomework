Укажите, что означает размер входа в вашей оценке сложности. Объясните идею своими словами.
Размер входа это количество данных который подается на вход функции, и именно от размера входа идет расчет сложности фукнции

Функция - `HasDuplicate`
В текущей функции размер входа N это кол-во элементов в списке a []int.
1. Как работает и почему выбран этот способ:
- Для решения этой задачи было выбрано множество, так как за один проход по циклу O(n) мы за O(1) проверяем встречался ли элемент, 
если рассматривать решение через вложенный цикл то работа алгоритма займет O(n2), 
если рассматривать способ сортировкой при котором одинаковые окажутся соседят то работа займет O(n log n).
2. Время и почему: 
- O(n) один проход цикла по срезу, операции с map в среднем занимают O(1).
3. Дополнительная память и почему:
- Память O(n) так как создается map внутри функции который в худшем случае запишет все n элементы.
4. Мои случаи и ожидаемые ответы:

- `{"повтор отрицательных элементов", []int{-1, 2, 3, -1}, true},`
- `{"повтор отрицательных элементов в самом конце", []int{0, 1, 2, 3, -5, -5}, true},`
- `{"все отрицательные элементы одинаковые", []int{-3, -3, -3}, true},`

Функция `IsAnagramSort`
В текущей функции размер входа N это длина каждой из строк а, b string
1. Как работают и почему выбран этот способ:
- Для решения этой задачи был использован метод сортировкой через встроенный пакет slices.
2. Время и почему:
- создаем два среза рун это занимает O(n), сортировка занимает O(n log n), и сравнение через Equal занимает O(n), отбрасываем слагаемые и остается итоговая сложность O(n log n)
3. Дополнительная память и почему:
- Два среза рун занимают O(n) памяти, slices.Sort и slices.Equal выделают памяти O(1), поэтому оставляем наибольшее по росту O(n)
4. Мои случаи и ожидаемые ответы:
- `{"кот", "котаа", false},`
- `{"ток", "", false},`
- `{"", "кот", false},`

Функция `IsAnagramMap`
В текущей функции размер входа N это длина каждой из строк а, b string
1. Как работают и почему выбран этот способ:
- Для решения этой задачи был использован словарь для хранения руны символа и счетчик сколько раз встретилась эта руна.
2. Время и почему:
- Первые два цикла выполняются за O(n) время последний цикл выполняется за O(m) где м кол-во уникальных ключей к примеру в слове может быть несколько букв а, 
например слово таракан, тогда по одному ключу А будет лежать значение 3 и последний цикл пройдет за O(m), но это лучший случай в итоге весь алгоритм работает за O(n)
3. Дополнительная память и почему:
- Пустая мапа дает O(1), первый цикл память растет до O(a) тут зависит от того сколько уникальных ключей может быть, опять же берем худший случай O(n), 
проход по второму циклу в памяти так же занимает O(n), это случай если одинаковых рун вообще нет, последний проход по мапе дает O(1), в итоге берем худший случай O(n)
4. Мои случаи и ожидаемые ответы:
- `{"кот", "котаа", false},`
- `{"ток", "", false},`
- `{"", "кот", false},`
